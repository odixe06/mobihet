# Index file toàn dự án

Danh mục tự sinh bằng `python3 scripts/update_file_index.py`. Định tuyến theo nhu cầu: [README](../README.md).

Liệt kê 1252 file workspace không bị ignore; dùng `rg`, không cần commit/stage. Không đọc nội dung file. Artifact/data/key bị ignore được định tuyến theo thư mục bên dưới, không liệt kê từng checkpoint.
