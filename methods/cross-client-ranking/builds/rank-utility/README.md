# CrossClientRank utility

[Contract, provenance, gates](../../../../docs/methods/cross-client-ranking/builds/rank-utility/README.md).

`source/proj`: source riêng frozen khi PUSHED, không sửa40mh hoặc rank-probe.
`scripts/check_rank_utility.py`: algebra/NNLS/codec/bounded synthetic SGD/state replay.
`scripts/check_rank_driver.py`: actual tiny driver fork/atomic checkpoints/resume/tamper fixture.
`scripts/check_rank_notebooks.py`: emitted cost/utility controller failure/budget fixtures.
`scripts/audit_mount.py SEED`: CPU mounted SHA/20strict warm models.
`scripts/check_bytes_compat.py`: empty CE wire regression, scoped bytes launcher, actual r3 audit.
`scripts/gen_rank_recovery.py SEED`: operational recovery từ audited r3, source/fingerprint không đổi.
`scripts/check_recovery_controller.py`: imported r3/compat/resume/costFAIL/workerFAIL/budget fixtures.
`scripts/audit_recovery_mount.py SEED`: mounted r3 SHA/state/wire/predictions proof trước recovery GPU.
`scripts/inspect_startup.py`: initial W&B exact fingerprint/progress, dừng polling khi ổn định.
`scripts/collect_rank_utility.py`: terminal owner-scoped resumable pull + exact-source/state/prediction audit.
`scripts/report_rank_utility.py`: fixedr20 paired gates và đủ10metrics, không fabricated warm-up metrics.
